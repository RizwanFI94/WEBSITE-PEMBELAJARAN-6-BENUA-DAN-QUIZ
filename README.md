# 🌍 Website Pembelajaran Mengenal 6 Benua di Dunia

Website pembelajaran interaktif untuk membantu siswa kelas 6 SD/MI mengenal enam benua di dunia melalui materi, gambar, dan permainan edukatif.

## 📖 Deskripsi Proyek

Website ini dibuat sebagai media pembelajaran mata pelajaran IPAS (Ilmu Pengetahuan Alam dan Sosial). Materi disajikan secara sederhana dan interaktif agar siswa lebih mudah memahami karakteristik setiap benua.

## 🎯 Tujuan Pembelajaran

- Mengenal enam benua di dunia.
- Mengetahui karakteristik setiap benua.
- Memahami letak geografis dan informasi setiap benua.
- Menguji pemahaman melalui kuis interaktif.

## ✨ Fitur Website

- **Beranda:** Halaman utama website.
- **Tujuan Pembelajaran:** Menampilkan tujuan pembelajaran.
- **Materi:** Informasi mengenai enam benua.
- **Kuis:** Latihan soal interaktif.
- **Cocokkan:** Permainan mencocokkan jawaban.
- **Pop Balon:** Permainan edukatif pop balon.
- **Benar/Salah:** Permainan untuk menguji pemahaman.
- **Skor:** Menampilkan hasil kuis.
- **Profil Penyusun:** Informasi pembuat website.

## 🌎 Materi Pembelajaran

1. Benua Asia
2. Benua Afrika
3. Benua Eropa
4. Benua Amerika Utara
5. Benua Amerika Selatan
6. Benua Australia
